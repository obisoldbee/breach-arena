# BREACH — 可破坏掩体多人竞技场

浏览器俯视角射击原型：2–6 人房间、可破坏砖墙、近距离按键语音，以及明确标注的三机器人练习模式。

## 这份仓库是什么

游戏、网络客户端和服务端逻辑来自已部署版本 `812bae3c4f57840b665f2a3caa6b4952b997b850`。原部署使用 Vinext + Cloudflare D1；完整原始工程位于 `deployed-source/`，保留原入口、依赖锁文件、组件与第三方许可，仅移除了 `.openai/hosting.json` 的部署项目 ID。该目录中的 README 是框架原始说明，不是独立部署教程。

仓库根目录提供轻量的独立 Cloudflare Worker 运行方式。它不是重写游戏：`public/`、`src/worker-handler.js` 和两份 SQL 迁移与上述版本完全一致。新增 `src/index.js` 只负责 API 路由、首页重定向和静态资源；测试改为直接导入这些文件，避免依赖私有 Sites 发布环境。没有附带原仓库 Git 历史、线上数据库或访问凭据。

## 本地运行

需要 Node.js **22.13 或更新版本**及 npm。所有命令从仓库根目录执行。

```bash
npm ci
npm run db:local
npm run dev
```

打开 `http://127.0.0.1:8787`。用两个标签页分别创建、加入同一个房间。数据库占位 ID 可以用于本地模拟，不会连接原站点数据库。`npm run db:local` 只初始化本地数据。

```bash
npm test        # 游戏回归 + SQLite 信令/权限/传输测试
npm run build  # Worker 打包 dry-run；不发布
```

## 部署到自己的 Cloudflare 账户

需要 Cloudflare 账户及 Workers/D1 可用额度；本项目不承诺永久免费。HTTP 兼容模式会持续读写 D1，实际费用依流量和平台计价。

```bash
npx wrangler login
npx wrangler d1 create breach-arena
```

将输出的真实 `database_id` 填入 `wrangler.jsonc`，保持绑定名称 **DB**。Worker 名称可自行修改。然后执行：

```bash
npm run db:remote
npm run deploy
```

远程迁移针对你配置的数据库执行；不要填入不属于此项目的数据库。认证交给 Wrangler，不要把 token、`.env`、`.dev.vars` 或本地数据库提交到仓库。浏览器麦克风需要 HTTPS 或 localhost 安全上下文。

## 玩法

WASD 移动，鼠标瞄准，按住鼠标射击，Space 冲刺，R 换弹，V 按住说话（先主动开启语音并授予麦克风权限）。每轮 3 分钟，24 发弹匣；死亡后复活，有短暂护盾。砖墙可摧毁，混凝土不可破坏。支持合成音效开关。

房主模拟整个世界，其他玩家发送输入。房主要保持页面在前台；房主退出后房间结束，**没有房主迁移**。这是可玩的原型，不是服务器权威的竞技反作弊系统。

## 连接和语音的边界

优先使用 WebRTC 数据通道。使用公共 STUN，**没有配置 TURN 中继**；某些防火墙/NAT 环境无法直连。约 10 秒仍未直连时，游戏自动切换到约 4 Hz 的 HTTPS 兼容同步，页面会提示高延迟；已直连玩家仍可用 WebRTC。

**HTTPS 兼容同步不传语音。**近距离语音依靠 WebRTC，按距离衰减，远处或死亡玩家静音，麦克风默认关闭。项目没有录音功能。距离规则有自动化测试，但尚未完成真实双人麦克风端到端验证，不能据此承诺语音已在所有网络可用。

房间最多 6 人；会话失联约 45 秒过期，房间最长约 2 小时。会话 token 在服务端以哈希保存；存在同源检查、请求体上限及部分接口限速。这些措施不等同于完整安全审计。

## 实际验证范围

2026-10-26 的部署版验证：46 项信令、权限、容量、TTL、传输及语音距离逻辑检查通过；9 类游戏回归通过；Vinext 构建通过。云浏览器双标签页实际完成创建/加入房间、HTTPS 兼容模式同步、房主移动同步、客人开火破坏掩体、房主离开后客人返回大厅。练习模式显示 3 个机器人。

该浏览器环境 WebRTC 未取得 ICE candidate，因此没有把信令协商成功当作直连成功；**实际 WebRTC 数据和麦克风通话未验证**。移动触屏控制代码存在，未完成真机测试。

2026-10-27 公开版验证见 `VERIFICATION.md`。自动化通过不代表所有浏览器和网络环境均已覆盖。

## 目录

- `public/game/`：游戏引擎、渲染、界面、音效和精灵图。
- `public/network/`：WebRTC、信令、HTTPS 兼容同步和近距离语音。
- `src/`：独立 Worker 入口及原版 API 处理器。
- `migrations/`：原版两阶段 D1 数据库迁移。
- `tests/`：针对实际公开代码与迁移的自动化测试，无线上用户数据。
- `deployed-source/`：完整 Vinext 部署源码快照，便于追溯；与根目录副本不要混用依赖命令。
